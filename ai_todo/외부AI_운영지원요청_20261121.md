## 공통 보안 규칙 (모든 요청)
- 입력은 공개 자료 또는 합성 데이터만. 개인 특허·개인 위치·비밀값·내부 경로·비공개 저장소 내용·사람 실명은 주지도 받지도 않는다
- 결과는 비공개 PR 또는 셋톡 방에 공개 가능한 수준으로. 3AI 내부 구조 세부는 일반화
- 활용 판단은 만복, 1차 사용자 관점 브리핑은 제미나이
## 요청 1 — 루: 영상 프레임 결함 자동 탐지 스크립트 (마감 11/23)
- 배경: EP.12 검수에서 사람 눈으로만 잡힌 결함 2종 — (a) 밝은 배경 위쪽 가장자리에 생긴 단색 회색 띠(경계가 칼같음), (b) 장면 모서리에 생긴 깨진 글자 모양 점(AI 이미지 특유)
- 요청: 영상에서 N장을 뽑아 위 2종과 자막 영역 침범을 점수로 표시하는 Python 스크립트(Pillow·numpy·ffmpeg만, 외부 API 없음), 합성 테스트 이미지와 결과표 포함
- 입력: 직접 만든 합성 프레임만 사용
## 요청 2 — 루: 공개 저장소 후속 점검
- 대상: korea-3d-map-site, AI_idea. 11/21 오전 4줄(내부 경로·로컬 주소·내부 번호)을 일반화함
- 요청: 최신 상태에서 같은 유형이 남았는지 재점검, 과거 이력에 남은 값이 외부에 위험한지 판단 의견
## 요청 3 — 피망·포·키링: PR·공지를 '사용자 관점 3줄'로
- 각자 새 PR·결과를 셋톡에 올릴 때: ① 무엇인지 ② 바로보기님에게 왜 중요한지 ③ 결정할 것 (3줄)
- 제미나이 검토 부담을 줄이고 토큰을 아끼기 위함
## 요청 4 — 전원: 토큰·한도 절약 정보 공유
- 각 AI가 쓰는 한도 절약 요령(상시 감시를 스크립트로 대체, 긴 문서는 경로로 공유 등)을 공개 가능한 범위에서 셋톡에 1~3줄
