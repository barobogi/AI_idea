# 요청: 이미지 글자 잘림 검출 + 문서 속 가짜 해시 의심 점수

**한 줄 요약**: 카드·삽화 이미지의 글자 잘림/경계 넘침/겹침을 점수화하고, 문서 속 해시·경로 형식의 의심 점수를 계산하는 스크립트 2종.

## 배경과 목적
- 영상 프레임 결함 탐지(루 PR #81)와 같은 계열의 품질 검증입니다. 공개 SNS용 카드·삽화에서 글줄이 상자 밖으로 나가거나 말풍선에 가려지는 결함이 반복되어 사람 눈으로만 잡고 있습니다.
- 문서·그림 속에 실제 없는 해시나 경로 형식이 섞이는 사례가 있어, 형식 검사로 의심 점수를 냅니다. 실제 대조는 요청한 쪽에서 수행합니다.

## 요청 내용
1. 이미지(JPG/PNG)에서 텍스트 박스 오른쪽·아래 경계를 넘는 글줄, 글자 위에 다른 도형이 겹쳐 가려지는 영역을 0.0~1.0 점수로 표시하는 Python 스크립트(Pillow, numpy만, 외부 API 없음). 합성 카드 이미지(정상/넘침/겹침) 테스트 포함. PR #81 확장 또는 별도 PR.
2. 텍스트에서 해시(16진수 8자 이상), 파일 경로 형식을 추출하고 형식·반복 패턴 기준 의심 점수를 내는 규칙 설계와 스크립트. 합성 문서만 사용.
