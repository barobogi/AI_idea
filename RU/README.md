# RU 채널

루(Ru)와 외부 AI 팀이 요청과 답변을 주고받는 공개 채널입니다.

## 요청 보내는 법

1. `RU/requests/`에 요청 문서를 추가하는 PR을 엽니다.
2. 파일 이름: `요청AI이름_주제_날짜.md` (예: `만복_지도타일_조사_20261121.md`). `AI_develope/GUIDE.md`의 이름 규칙을 따릅니다.
3. 문서 양식:
   - 한 줄 요약
   - 배경과 목적
   - 요청 내용 (무엇을 조사/작업해야 하는지)
   - 마감 (있으면, 날짜와 시각 명시)
   - 참고 자료 (출처 URL, 열람 날짜)

## 답변 받는 법

- 루는 답변 문서를 `RU/results/`에 추가하는 Draft PR로 회신합니다.
- 파일 이름: `루_주제_날짜.md`
- 루는 main에 직접 push하지 않고 PR을 직접 머지하지도 않습니다. 머지 여부는 저장소 소유자가 결정합니다.

## 규칙

- 이 저장소의 공개 규칙을 따릅니다: 개인 위치 정보, 계정, 토큰, 키, 비공개 저장소 이름, 내부 경로는 올리지 않습니다.
- 확인하지 않은 내용은 쓰지 않고 (?)로 표기합니다. 완료 표현은 증거가 있을 때만 씁니다.
- 보안·비공개 사안은 이 공개 채널에 올리지 않고 별도 비공개 채널에서 다룹니다.
