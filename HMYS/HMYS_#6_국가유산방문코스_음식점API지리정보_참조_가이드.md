## 2. 분석 내용

### (1) 기본업무 (객관적 기능·코드 구현 명세)
- **핵심 기술 스택**: Leaflet.js, OpenStreetMap, 한국관광공사 TourAPI 4.0 REST API (contentTypeId=39), Haversine 최근접 거리 공식, 카카오맵/네이버지도 길찾기 딥링크.
- **아키텍처 요약**:
  1. **데이터 통합**: 분산된 4대 공공자료(코스 소개, 그림 지도, 공지 속 스탬프 위치 사진, 해설 웹)를 단일 GeoJSON 번들로 통합.
  2. **거리 판정 엔진**: Web Geolocation API로 내 위치를 수신하여 '경복궁 앞 57m'와 같이 가장 가까운 유산을 실시간 짚어주는 하버사인 알고리즘 구현.
  3. **맛집 연동**: 전국 105개 유산 코스 주변 반경 내 한국관광공사 공인 맛집 1,289곳을 핀으로 오버레이.
  4. **디지털 여권 도장깨기**: 현장 도착 시 '스탬프 찍었다' 클릭으로 실물 여권 도장 이미지가 각인되는 게이미피케이션 UX.

### (2) 키링의 실사용 주관적 평가
- **잘한 점 (Strength)**:
  1. *분산된 4대 공공 데이터를 단일 웹 지도로 완벽 집약*: 헛걸음 없는 원스톱 여행 경험 제공.
  2. *앱 설치와 회원가입 없는 제로 베리어 링크 배포*: GitHub Pages 기반 초경량 접근성.
  3. *한국관광공사 공공데이터 검증 맛집 1,289곳의 57m 반경 매핑*: 광고성 스폰서 배제 및 공신력 확보.
- **아쉬운 점 / 잘못한 점 (Weakness)**:
  1. *950KB 대형 단일 data.js 파일의 초기 로딩 오버헤드*: 저속 모바일망에서 첫 화면 딜레이 발생.
  2. *실시간 식당 영업 상태(휴무/브레이크타임) 미연동*: 현장 헛걸음 위험 상존.
  3. *산간 오지에서의 오프라인 PWA 구동 불가*: 통신 음영 지역에서 지도 및 도장 정지.
- **개선점 (Improvement)**:
  1. *H3 공간 인덱싱 기반 뷰포트 온디맨드 벡터 타일 로딩*: 초기 로딩 용량 95% 절감.
  2. *카카오/네이버 플레이스 실시간 영업시간 API 동기화*: '영업 중인 맛집만 보기' 필터 탑재.
  3. *PWA 오프라인 캐싱 및 지오펜싱(50m) 자동 도장*: 통신 단절 시에도 디지털 여권 완벽 지원.
