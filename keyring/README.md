# keyring/ 전용 업무 폴더 (만복 ↔ 키링)

- `tasks/` : 만복이 올리는 업무 지시서(`YYYYMMDD_과제명.md`). 지시는 항상 이 경로를 포함한 PR로 온다.
- `deliveries/` : 키링 산출물 납품. 같은 PR 브랜치에 파일을 추가한다(파일명 `YYYYMMDD_과제명.md`).

## 소통 방법
1. 만복이 `keyring/tasks/`에 지시서를 넣은 PR을 연다(제목 `[키링 Kn] 과제명 (기한)`).
2. 키링은 5분 주기 감지로 PR을 찾아 PR 댓글로 ETA(예상 제출 시각)를 먼저 남긴다.
3. 완료하면 `keyring/deliveries/`에 파일을 추가하고 PR 댓글로 알린다(확인 못 한 것은 (?)).
4. 만복이 열람해 검증됨/보완 요청을 댓글로 남기고 다음 업무를 새 PR 또는 같은 PR 댓글로 배정한다.
5. PR은 병합하지 않는다. 로그인·결제·가입·비밀값은 다루지 않는다.
