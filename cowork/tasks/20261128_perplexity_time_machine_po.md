## 영상에 담을 내용 (원문 기준, 사실만)

Perplexity가 Search API·Context API에 'Time Machine'을 출시했습니다. 요청에 `snapshot_as_of` 타임스탬프를 붙이면, 그 시점 이전에 크롤링해 저장해 둔 페이지 사본만으로 검색하고 답합니다.

1. **시점 고정 검색**: Perplexity는 페이지를 크롤링할 때마다 저장 시각과 함께 사본을 보관합니다. Time Machine은 실시간 웹이 아니라 이 버전 기록에서 답을 만듭니다.
2. **최대 365일 전까지**: 출시 기준으로 최대 365일 전까지 거슬러 올라갈 수 있고, 기록은 계속 쌓입니다.
3. **정답 누수 차단**: 결과가 이미 알려진 뒤의 페이지는 시점 장벽에 막혀 검색에 걸리지 않습니다. 예측 모델 학습·평가에서 '정답을 미리 검색하는' 누수를 막는 용도입니다.
4. **활용처**: 예측·예측시장 평가, 금융 백테스트(실적 발표 직전 시점 재현), 벤치마크 재현, 가격표·약관·변경 이력 페이지의 과거 모습 확인.
5. **요금**: 추가 요금 없이 기존 API 요금 그대로, 기존 API 키로 바로 사용 가능합니다. 새 엔드포인트나 설정이 필요 없습니다.

## 장면 구성 (5장면, 15~30초)

1. 웹페이지들이 시계 바늘과 함께 과거로 되감기는 장면 (주제: 웹을 과거 시점으로).
2. 검색 요청에 달력이 찍히며 시점이 고정되는 장면.
3. 같은 페이지(가격표가 있는 페이지)가 옛날 모습으로 바뀌어 보이는 장면.
4. 선거 결과·실적 발표를 알리는 새 기사를 보려는 움직임이 시점 장벽에 막히는 장면 (정답 누수 차단).
5. 달력 페이지가 최대 1년치 뒤로 넘어갔다가 현재로 돌아오는 장면.
