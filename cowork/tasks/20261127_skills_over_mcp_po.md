## 영상에 담을 내용 (원문 기준, 사실만)

MCP(Model Context Protocol) 2주년을 맞아 Anthropic이 발표한 확장 묶음입니다. 구성은 3종입니다.

1. **Skills over MCP** (공개 베타): MCP 서버가 도구와 함께 스킬(사용법·절차 안내)을 배포합니다. 서버가 도구만 주는 게 아니라 '어떻게 쓰는지'까지 같이 건네는 구조입니다.
2. **Tasks** (정식 출시, GA): 서버가 긴 작업을 백그라운드로 돌리고, Claude는 그동안 다른 일을 계속하다가 결과가 준비되면 받아 갑니다.
3. **Elicitation** (정식 출시, GA): 도구 호출 도중 입력이나 확인이 필요하면 서버가 멈추고 사용자에게 입력·승인을 받습니다.

파일 업로드(File Uploads) 기능은 곧 제공 예정입니다. 이 기능들은 열린 MCP 규격과 그 확장의 일부라, 호환되는 다른 클라이언트에서도 같은 서버가 동작합니다. Anthropic 자체 수치(SDK 월 다운로드 수·커넥터 수 등)는 영상에 넣지 마세요.

## 장면 구성 (5장면, 15~30초)

1. 사용자가 Claude와 작업 중인데, 연결된 도구의 사용법을 몰라 막히는 장면.
2. MCP 서버가 도구 상자와 함께 설명서(스킬)를 건네는 장면.
3. Claude가 설명서를 펼쳐 여러 단계 작업을 척척 진행하는 장면.
4. 긴 작업을 서버에 맡기고 Claude는 다른 일을 계속하다가, 결과가 돌아오는 장면 (Tasks).
5. 중요한 순간(결제·삭제 느낌의 동작)에 서버가 멈추고 사용자에게 확인 창을 띄워 승인을 받는 장면 (Elicitation).
