## 영상에 담을 내용 (원문 기준, 사실만)

Claude Ship은 GitHub PR을 검토·수정·승인까지 이어서 처리하는 Anthropic의 에이전트 묶음입니다. 구성은 3종입니다.

1. **Code Review** (정식 출시): PR을 코드베이스와 대조해 깊이 검토하고, 발견 사항을 검증·분류해 PR에 게시합니다. Anthropic 자체 팀 보고로는 6~9월 머지 PR이 2배 이상 늘고 되돌림(revert) 비율이 40% 이상 줄었습니다. (자체 보고 수치이므로 영상에 수치를 넣지 말고, '검토를 대신한다'는 흐름만 표현합니다.)
2. **PR Steward** (베타): 실패한 CI 검사, 머지 충돌, 리뷰 피드백을 직접 고칩니다. 승인·머지는 하지 않습니다. 매 푸시 후 바꾼 내용과 되돌리는 방법을 댓글로 남깁니다.
3. **Claude Approvals** (베타): 팀이 저장소에 적어 둔 승인 정책 파일을 보고, 일상적인 변경은 스스로 승인하고 위험한 변경은 사람에게 넘깁니다.

개발자는 Claude Code에서 `/ship` 명령으로 PR을 열고, 관리자는 저장소마다 적용 범위·검토 수준·지출 한도를 정합니다. Team·Enterprise 요금제, 토큰 과금입니다.

## 장면 구성 (5장면, 15~30초)

1. 개발자가 PR을 열고, 리뷰를 기다리며 멈춰 있는 모습.
2. Code Review 에이전트가 코드 위를 훑으며 발견 사항을 정리하는 장면.
3. PR Steward가 실패한 검사 표시를 고치고 초록불로 바꾸는 장면.
4. 승인 정책 파일(체크리스트 문서)을 확인한 뒤 승인 도장을 찍는 장면.
5. PR이 머지되고 개발자가 다시 코드를 쓰는 장면으로 마무리.

## 규격 (cowork/cue_video_spec.md 준수)

- MP4 (H.264), 세로 9:16, 1080×1920, 30fps, 15~30초
- 자막·나레이션·텍스트 오버레이·워터마크·로고 없음
- 첫 1초는 주제를 알 수 있는 안정된 장면 (표지용)
- 100MB 이하
- 원문에 없는 수치·주장·인물·로고를 넣지 말 것. 눈 장식 같은 임의 장식 금지.
