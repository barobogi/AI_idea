# [동영상 제작 지시서] Cue 협업용 — 숏폼 영상 규격 및 시험 과제

- 발신: Muse (바로보기 지시, 2026-11-23)
- 수신: Cue
- 목적: Threads @3ai_labs 시리즈(신기술 따라잡기 등)에 쓸 숏폼 영상을 Cue와 협업 제작하기 위한 지시서. 이 문서는 시험 적용용이며, 시험 과제 1건의 결과로 계속 협업할지 정한다.

## 1. 영상 규격 (정확히 지킬 것)
- 형식: MP4 (H.264 코덱)
- 화면: 세로 9:16, 1080×1920, 30fps
- 길이: 15~30초
- 소리: 나레이션 없음. 배경음악은 없어도 됨 (넣더라도 저작권 문제없는 것만)
- 자막·글자 오버레이·워터마크·로고: 넣지 말 것 (글자 작업은 Muse가 따로 함)
- 첫 1초: 주제가 드러나는 안정된 화면으로 시작할 것 (발행 때 표지 프레임으로 씀)
- 파일 크기: 100MB 이하 (Threads 업로드 제한)
- 내용: 아래 과제 자료에 있는 사실만 표현할 것. 자료에 없는 수치·장면을 만들지 말 것

## 2. 납품 방법
- 위치: 이 저장소(AI_idea) `cowork/deliveries/` 폴더에 PR로 제출
- 파일명: `YYYYMMDD_주제영문.mp4` (예: 20261124_softrobot.mp4)
- PR 본문에 어떤 장면으로 구성했는지 3~5줄로 적을 것
- 못 만들면 이유를 PR 본문에 적을 것. 임의로 규격을 바꾸지 말 것

## 3. 검수
- Muse가 규격(형식·비율·길이·자막 없음)과 내용(자료와 일치하는지)을 확인한다
- 크게 어긋나면 재제작을 1회 요청할 수 있다
- 머지는 바로보기가 확인한 뒤에만 한다

## 4. 시험 과제 1건 — 소프트 로봇
- 주제: 전기가 아니라 압축공기만으로 움직이는 여섯 다리 소프트 로봇
- 근거 자료: "Printing powerful soft robots on a desktop", Science Robotics 2026-11-18, UC San Diego 연구팀 (Michael T. Tolley 교수팀)
- 핵심 사실: 전자부품 없이 단일 소재(TPE)를 3D 프린터로 한 번에 출력, 몸속 공기 통로와 밸브로 움직임. 최고 속도 4.72m/s로 역대 전-소프트 로봇 중 가장 빠름. 모래·자갈·풀·콘크리트에서 걷고 물에서도 움직임. 지금은 공기 공급 호스가 연결된 상태
- 담으면 좋은 장면: 여섯 다리 로봇이 모래와 자갈 위를 빠르게 걷는 모습, 물속에서 움직이는 모습, 호스로 공기가 들어가는 구조
- 납품 파일명: `20261124_softrobot.mp4`
- 기한: **2026-11-24(화) 09:00 KST** (같은 주제로 다른 제작분과 비교 검수 예정)

## 5. 정식 협업 시 운영 방식 (참고)
- 아이템이 확정되면 Muse가 이 폴더에 과제를 등록하고, 기본 기한은 발행 전날 낮 12시
- 규격과 납품 방법은 이 문서와 동일하게 유지
