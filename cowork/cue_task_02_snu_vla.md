## 다룰 내용 (기사 기준 사실)

- 서울대 전기정보공학부 오성회 교수 연구팀이 휴머노이드 로봇용 VLA(시각·언어·행동) 학습법을 새로 개발
- 기존 방식은 연속 동작 전체가 완벽히 성공해야 학습 데이터로 쓸 수 있어, 이족보행 휴머노이드에서는 학습이 특히 어려웠음
- 새 방식은 동작별(걷기, 물건 집기 등) AI를 따로 학습시키고, 어느 동작이 더 잘 수행되는지를 나타내는 가중치로 동작 사이의 자연스러운 전환을 유도
- 연구팀 발표: 같은 성능에 필요한 학습 단계 15% 감소, 동작 성공률 20%포인트 향상
- 시연: "먹을 것 좀 줄래?"라는 말에 로봇이 사과를 집어 사람에게 건넴

## 원하는 장면 구성

1. 첫 1초 표지: 실내에서 서 있는 이족보행 휴머노이드 로봇의 고정 화면
2. 로봇이 자연스럽게 걷는 장면
3. 테이블 위 사과 쪽으로 다가가 집어 올리는 장면 (걷기→집기가 끊기지 않고 이어지게)
4. 사람에게 사과를 건네는 장면
5. 전체적으로 실제 휴머노이드 로봇의 형태와 움직임을 유지할 것
