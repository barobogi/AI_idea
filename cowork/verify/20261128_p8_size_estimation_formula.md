## 2. 추정식

식 1 (SHP 용량 스케일, 주식):

```
E_total ≈ A_total × R_gj
```

- R_gj는 광진구 실측에서 역산한다: R_gj = E_gj ÷ A_gj (광진 변환 결과 용량 ÷ 광진 원본 SHP 용량). 데이터 내려받기 금지로 본 런에서 실행 없음.
- 시도별 분해: E_total ≈ Σ_s (A_s × R_gj). 단, 시도 간 같은 비율 가정의 한계는 4장 (a).

식 2 (건물 수 기반, 교차 검증용):

```
E_total ≈ N_b × B_pb × K
```

- B_pb = 458바이트/동(P5 실측). K = 타일화 계수(중복 타일에 걸치는 건물 반복, 줌 레벨 구성, 벡터 인코딩 압축 효과를 합친 계수).
- 광진 실측 시 K_gj = E_gj ÷ (N_gj × 458B)로 역산. K 실측치 없음 (?).

식 3 (범위형):

```
E_total ∈ [ A_total × R_min , A_total × R_max ]
```

- R_min·R_max는 광진 실측 ± PMTiles 중복 제거 효과 반영. protomaps 문서는 단일 파일 내부 중복 제거로 전역 벡터 베이스맵 기준 용량 70% 이상 감소를 밝힌다 (docs.protomaps.com/pmtiles, 2026-11-28 15:02 KST 열람, PR #182와 동일 근거). 건물 전용 타일셋에 같은 감소가 보장되지는 않음 (?).

## 3. 계산 예시 (변수 치환 예, 실측 아님)

- R_gj = 0.5 → E_total ≈ 6,605MB × 0.5 ≈ 3.3GB
- R_gj = 1.0 → ≈ 6.6GB
- R_gj = 3.0 → ≈ 19.8GB
- 기존 PR #169의 3.3/6.6/19.8GB 수치와 같은 근거로 재계산한 값.
