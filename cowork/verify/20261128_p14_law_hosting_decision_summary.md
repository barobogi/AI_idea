## ① 확인된 사실 (5줄)

1. 브이월드 국외 접속 제한 공지가 밝힌 근거는 '국토교통부 국가공간정보 보안관리규정 제13조'이고(P11·P12, 원문은 해외 IP에서 직접 열람 불가(?)), 공간정보관리법 제16조는 기본측량성과 중 '지도등'·'측량용 사진'의 국외 반출을 금지한다(법률 제21447호, 시행 2026.7.1., P10).
2. 규정 제13조의 적용 대상은 국토교통부 본부·소속기관·산하 공공기관('관리기관')이고, 민간 개인에 대한 직접 적용 조항은 규정 본문에서 확인하지 못했다(?). 공개 구분은 제6조 3분류(비공개·공개제한·공개)이며 제13조의 반출 금지는 '비공개·공개제한'만을 대상으로 한다(P12).
3. 전국 건물 데이터는 14,422,486동·원본 6,605MB(공간포털 메타데이터 실측, P5)이고 3D 가공 후 총량 시나리오는 3.3GB(낙관)~6.6GB(중간)~19.8GB(보수)다. GitHub Pages는 게시 사이트 1GB 상한·파일 100MiB 하드 블록·월 100GB 소프트 대역폭이라 전국 단일 호스팅 기준 용량에 걸린다(P8·P9).
4. PMTiles 단일 파일은 HTTP Range 요청을 전제로 하고, Cloudflare R2는 객체 5TiB·Range 공식 구현으로 요건을 문서상 만족한다. GitHub Pages의 Range 지원은 공식 문서에서 확인하지 못했다(?)(P9).
5. 국내에서 다운로드한 CC BY SHP를 해외 인프라에 올려 공개한 공식 질의회신·인정 사례는 확인하지 못했고(?), 공식 사례로는 구글 1:5,000 지도 조건부 허가(2026-02-27 협의체 결정: 국내 서버 가공·국내 상주 전담관·레드버튼 등)가 유일하다(P11·P12). molit FAQ 첨부(2018-12 등록)의 질문 10개에 해외 이용 관련 질문은 없다(?)(P13).

## ③ 호스팅 길별 남는 위험

**GitHub Pages 유지** — 기술: 1GB 사이트·100MiB 파일·월 100GB 대역폭(소프트)·10분 배포 타임아웃에 걸리고(P8), Range 지원 근거가 없어 PMTiles 단일 파일과 맞지 않는다(?) (P9). 법: 해외 인프라라 국내 호스팅 제약 이슈가 그대로 남는다(단정 없음, P10~P12). 약관: GitHub Pages는 상업적 서비스 용도를 권장하지 않는다(P8).

**국내 서버(예: NCP Object Storage + Global Edge)** — 법: 데이터가 국내에 보관되므로 '국외 반출' 이슈 자체는 피하는 구조이나, 해외 방문자에의 전송·CDN 경유가 어떻게 보이는지는 공식 근거가 없어(?) 판단 불가. 기술: 용량·Range 조건은 충족 가능(루 REQ166·167 참고). 비용: 월 전송 100GB 8,649~9,139원, 1TB 86,265~86,755원(루 REQ163 계산, 크레딧 10만원 3개월 조건부). 운영: 개인 계정은 신용카드만(체크카드 ?), 해외카드는 3D-Secure·USD/JPY만, 크레딧 만료 후 미해지 서비스 자동 과금(루 REQ164, 공식 문서 기준).

**Cloudflare R2** — 기술: 5TiB 객체·Range 공식 구현·버킷 CORS로 PMTiles 요건을 문서상 충족, r2.dev 도메인은 스로틀 있음(?) (P9). 법: 해외 인프라라 GitHub Pages와 같은 국내 호스팅 제약 이슈가 남는다(단정 없음). 비용: 루 REQ163 이전 비교 대상.

**보조: 네이버 MYBOX** — 공유 링크가 뷰어 페이지·1회용 Open API URL이라 공개 웹 자산 서빙 용도 부적합, 약관상 개인 사용 범위(루 REQ167). 내부 원본 보관·백업용으로만 적합.

## ④ 바로보기님이 직접 문의하면 좋을 질문 3개 초안 (공식 문의 문체)

**질문 1 (브이월드 고객센터 1661-0115 / 국토지리정보원) — CC BY 데이터의 해외 서버 업로드**
"안녕하십니까. 브이월드 데이터센터에서 공공데이터 CC BY 라이선스로 제공되는 GIS건물통합정보(SHP)를 국내에서 정상적으로 다운로드하여 이용 중인 개인 이용자입니다. 다음 사항에 대한 공식 입장 또는 관련 질의회신 사례가 있는지 문의드립니다. 국내에서 다운로드한 해당 데이터를 해외에 서버를 둔 인프라(Cloudflare R2, GitHub Pages 등)에 업로드하여 웹에서 공개하는 행위가 공간정보관리법 제16조 또는 국토교통부 국가공간정보 보안관리규정 제13조의 '국외 반출'에 해당하는지 여부, 그리고 해당한다면 승인 절차의 시작 창구를 알려주시기 바랍니다."

**질문 2 (같은 창구) — 국내 서버 보관 + 해외 방문자 전송**
"안녕하십니까. 공간정보 관련 개인 프로젝트를 진행 중인 이용자입니다. 동일 데이터를 국내 서버(국내 클라우드 Object Storage)에 보관하고, 해외에 거주하는 이용자가 웹에서 조회·다운로드할 수 있도록 공개하는 형태가 허용되는지, 이 경우 국외 CDN(Cloudflare Global Edge 등)을 경유하는 구성이 별도 승인 대상인지 문의드립니다. 관련 공식 안내 문서가 있다면 함께 안내를 부탁드립니다."

**질문 3 (국토지리정보원) — 기본측량성과 해당 여부와 고시 범위**
"안녕하십니까. 공간정보관리법 제16조의 '기본측량성과' 범위에 관해 문의드립니다. ① 국토지리정보원 고시 '측량성과의 종류 등' 전문을 열람할 수 있는 경로, ② GIS건물통합정보(수치지형도 2.0 건물레이어+건축물대장 속성 통합)가 그 고시상 기본측량성과에 해당하는지, ③ 국토지리정보원 예규 '국가공간정보 보안관리규정' 별표 1의 최종 시행 버전 확인을 부탁드립니다."
