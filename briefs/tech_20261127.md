## 1. **OpenAI Private Inference** (컨피덴셜 컴퓨팅 기반 프라이빗 추론)

- **발표한 곳**: OpenAI (Sam Altman X 공지 + OpenAI Private Intelligence 페이지)
- **발표일**: 2026-11-25 (Altman X 게시 11-25 17:12 UTC 확인)
- **원문 링크**: https://openai.com/business/private-intelligence/
- **무엇인지**: 기업 고객 대상 alpha 테스트로, 프롬프트·응답이 모델 처리 중에도 보호되도록 confidential computing과 검증 가능한 엄격한 통제를 결합한 기능. Zero Data Retention + Private Safety Processing과 묶여 기업 데이터가 저장 후반부뿐 아니라 처리 시점에도 보이지 않게 만든다.
- **왜 볼 만한지**: 금융·의료·법률처럼 기밀성이 전제인 기업 워크로드가 프론티어 모델을 쓸 수 있게 하는 문턱이며, Altman이 비공개 고객군 테스트 시작을 직접 공표한 시점이라 GA 전 기업 도입 설계의 참고점이 된다.

## 2. **Cloudflare Search for Agents** (웹사이트를 에이전트 검색 대상으로 만드는 원클릭 스위치)

- **발표한 곳**: Cloudflare (공식 블로그 "Introducing Search for Agents")
- **발표일**: 2026-11-25
- **원문 링크**: https://blog.cloudflare.com/search-for-agents/
- **무엇인지**: 대시보드 토글 하나로 자기 도메인을 색인해 AI 에이전트용 검색 엔드포인트 /.well-known/search 를 노출하는 베타 기능. 무료 포함 전 플랜에서 사용 가능하고, GET과 RFC 10008(2026-06 발행)의 HTTP QUERY 방식을 지원한다.
- **왜 볼 만한지**: 에이전트가 사이트를 크롤링하지 않고 검색으로 콘텐츠를 소비하는 흐름을 사이트 소유자가 스위치 하나로 맞이할 수 있게 한 것이며, AI Search 유료화(2026-12-01부터) 앞둔 에이전트 트래픽 수급의 선례가 된다.

## 3. **Perplexity Time Machine** (과거 시점의 웹을 보여주는 Search·Context API 파라미터)

- **발표한 곳**: Perplexity (공식 블로그 + Perplexity Developers X + API 문서)
- **발표일**: 2026-11-25
- **원문 링크**: https://www.perplexity.ai/hub/blog/freeze-the-web-with-perplexity-time-machine
- **무엇인지**: Search·Context API 요청에 snapshot_as_of 타임스탬프를 붙이면 해당 시점 이전에 크롤링해 저장한 페이지 사본만으로 답하는 기능. 출시 기준 최대 365일까지 거슬러 올라가며, 기존 API 키로 즉시 사용 가능하고 추가 요금은 없다.
- **왜 볼 만한지**: 예측 모델 학습·평가에서 "정답을 미리 검색하는" 누수를 원천 차단해 RL 학습 신호 개선을 검증했다고 밝혔고(자체 발표 수치), 하루 앞서 xAI 출신 창업자의 Epochal Time Portal이 나오며 '시점 고정 웹 검색'이라는 새 카테고리 경쟁이 열렸다.
